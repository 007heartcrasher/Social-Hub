Social Hub APK build (mobile-only)

1. GitHub par sign in karein aur New repository banayein, naam SocialHub, Public ya Private.
2. Is folder ke andar ki tamam files aur folders repository ke root mein upload karein. Hidden .github folder bhi upload hona chahiye.
3. Repository ke Actions tab mein "Build Social Hub APK" workflow kholein. Agar workflow run na ho to Run workflow dabayein.
4. Run complete hone par run page ke neeche Artifacts mein SocialHub-debug-apk download karein.
5. ZIP artifact extract karein. app-debug.apk par tap karke install karein. Android poochay to browser/files app ko Install unknown apps permission dein.

Note: APK debug/test build hai. Social media services may open in WebView/mobile web; it does not provide all official native app features. Never upload passwords or API keys.
